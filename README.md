# MTTL Control

تطبيق أندرويد للتحكم في مشتركات MTTL-W01 على شبكتك المحلية.
المشترك بيتصل بالموبايل مباشرة على المنفذ 10086، فلازم التطبيق يفضل مفتوح والموبايل على نفس الواي فاي.

## التحميل من GitHub
1. ارفع المحتويات على مستودع جديد.
2. ادخل Actions، وانتظر البناء يخلص.
3. حمّل الـ artifact `mttl-control-apk` وثبّت `app-debug.apk`.
